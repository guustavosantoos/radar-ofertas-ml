Politica de Privacidade — Achadinho PRO

Ultima atualizacao: 20 de marco de 2026

A extensao Achadinho PRO ("nos", "nosso" ou "extensao") respeita a privacidade de seus usuarios. Esta Politica de Privacidade descreve quais dados coletamos, como os utilizamos e como os protegemos.

1. Dados que Coletamos

1.1 Dados de Produtos em Marketplaces

Quando voce navega em paginas de produtos no Mercado Livre ou Amazon Brasil, a extensao extrai informacoes publicamente disponiveis da pagina:

  • Nome do produto, preco, preco original, percentual de desconto
  • Imagem do produto (URL publica)
  • Nome do vendedor, avaliacao, quantidade de vendas
  • Informacoes de frete e condicao do produto
  • Categoria do produto

Estes dados sao extraidos apenas das paginas que voce visita ativamente e somente enquanto a extensao esta aberta.

1.2 Dados de Autenticacao

  • Email e senha para login no servico Achadinho PRO (transmitidos via HTTPS, nunca armazenados localmente em texto puro)
  • Token de autenticacao (armazenado localmente para manter sua sessao)

1.3 Cookies

A extensao acessa cookies do Mercado Livre exclusivamente para verificar se voce esta logado no programa de afiliados do Mercado Livre. Esses cookies nunca sao copiados, transmitidos ou armazenados pela extensao.

1.4 Preferencias e Configuracoes

  • Filtros de busca (preco maximo, desconto minimo, frete gratis)
  • Configuracoes de agendamento de automacao
  • Listas de produtos salvas pelo usuario

1.5 Dados que NAO Coletamos

  • Historico de navegacao fora dos marketplaces suportados
  • Dados pessoais como CPF, endereco ou dados bancarios
  • Conteudo de outras abas ou sites nao relacionados
  • Dados de formularios ou campos de senha de outros sites

2. Como Utilizamos os Dados

  • Geracao de links de afiliado: Os dados do produto sao usados para gerar links de afiliado atraves da API oficial do programa de afiliados do Mercado Livre, utilizando a sessao do proprio usuario.
  • Salvamento de produtos: Produtos sao salvos no servidor do Achadinho PRO para que o usuario possa gerencia-los e utiliza-los em automacoes de divulgacao.
  • Automacao de buscas: Palavras-chave configuradas pelo usuario sao usadas para buscar produtos automaticamente e salvar os resultados.
  • Listas de produtos: Listas criadas pelo usuario sao armazenadas temporariamente (48 horas) para uso em campanhas de divulgacao.

3. Links de Afiliado — Divulgacao

O Achadinho PRO gera links de afiliado do Mercado Livre. Quando voce usa a extensao para gerar um link de produto, esse link contem seu identificador de afiliado do Mercado Livre. Quando alguem compra atraves desse link, voce pode receber uma comissao do Mercado Livre conforme os termos do programa de afiliados.

A extensao nunca substitui ou modifica links de afiliado de terceiros. Todos os links sao gerados explicitamente pelo usuario.

4. Compartilhamento de Dados

  • Servidor Achadinho PRO: Dados de produtos e configuracoes sao sincronizados com nosso servidor via conexao HTTPS criptografada para permitir o gerenciamento de produtos e automacoes.
  • Mercado Livre: A extensao interage com a API do programa de afiliados do Mercado Livre usando a sessao autenticada do proprio usuario para gerar links.
  • Terceiros: NAO vendemos, alugamos ou compartilhamos seus dados com terceiros para fins de marketing, publicidade ou qualquer outro proposito.

5. Armazenamento e Retencao

  • Armazenamento local (chrome.storage): Token de autenticacao, preferencias e configuracoes de agendamento.
  • Servidor: Dados de produtos e listas sao armazenados em banco de dados PostgreSQL com conexao criptografada.
  • Retencao: Listas de produtos expiram automaticamente apos 48 horas. Dados de produtos no servidor sao mantidos enquanto a conta do usuario estiver ativa.
  • Exclusao: Ao excluir sua conta, todos os dados associados sao removidos permanentemente.

6. Seguranca

  • Todas as comunicacoes entre a extensao e o servidor utilizam HTTPS (TLS 1.2+)
  • Tokens de autenticacao sao armazenados de forma segura no chrome.storage.local
  • Senhas nunca sao armazenadas localmente — apenas o token de sessao
  • A extensao nao executa codigo remoto (compliance com Manifest V3)

7. Permissoes Solicitadas

A extensao solicita as seguintes permissoes do Chrome, cada uma com um proposito especifico:

PermissaoMotivo
tabsDetectar quando voce navega em sites de marketplace suportados para extrair dados do produto.
activeTabInteragir com a aba ativa para extrair informacoes do produto que voce esta visualizando.
scriptingInjetar scripts nas paginas de marketplace para coletar dados publicos do produto (titulo, preco, imagem).
sidePanelExibir a interface principal da extensao como painel lateral para gerenciar produtos e automacoes.
storageSalvar suas preferencias, configuracoes e dados de sessao localmente.
notificationsNotificar quando tarefas de automacao sao concluidas ou quando acoes requerem atencao.
cookiesVerificar se voce esta logado no programa de afiliados do Mercado Livre para gerar links.
alarmsAgendar verificacoes periodicas para executar buscas automaticas de produtos.

8. Seus Direitos

Voce tem o direito de:

  • Acessar seus dados a qualquer momento atraves do painel do Achadinho PRO
  • Excluir seus dados solicitando a exclusao da conta
  • Exportar suas listas e dados de produtos
  • Desinstalar a extensao a qualquer momento, removendo todos os dados locais automaticamente

9. Alteracoes nesta Politica

Podemos atualizar esta Politica de Privacidade periodicamente. Notificaremos voce sobre mudancas significativas atraves de uma notificacao na extensao ou por email.
