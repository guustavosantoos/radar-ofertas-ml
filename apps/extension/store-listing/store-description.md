# Achadinho PRO — Chrome Web Store Listing

## Nome
Achadinho PRO — Afiliado Mercado Livre

## Descricao Curta (manifest.json — max 132 chars)
Ferramenta para afiliados do Mercado Livre. Extraia produtos, gere links de afiliado e automatize suas divulgacoes.

## Categoria
Shopping

## Descricao Completa (Store Dashboard — max 16000 chars)

---

**Achadinho PRO** e a ferramenta definitiva para afiliados do Mercado Livre que desejam encontrar, organizar e divulgar produtos com mais eficiencia.

IMPORTANTE: Esta extensao gera links de afiliado do Mercado Livre. Os links gerados contem o identificador de afiliado do usuario logado no programa de afiliados do ML. A extensao NAO substitui links de terceiros — todos os links sao gerados explicitamente pelo usuario.

━━━━━━━━━━━━━━━━━━━━━━━━

FUNCIONALIDADES PRINCIPAIS

Extracao de Produtos
- Extraia automaticamente dados de qualquer produto do Mercado Livre: nome, preco, desconto, vendedor, avaliacao e imagem
- Funciona em paginas de produto individual, listagens de busca e categorias
- Detecta automaticamente ofertas do dia e ofertas relampago

Geracao de Links de Afiliado
- Gere links encurtados de afiliado com um clique
- Utiliza sua conta do programa de afiliados do Mercado Livre (requer login previo)
- Links sao gerados localmente usando a sessao do seu navegador — seus dados nao sao compartilhados

Listas de Produtos
- Salve produtos em listas personalizadas para organizar suas campanhas
- Selecione multiplos produtos de uma pagina de busca e salve de uma vez
- Listas temporarias com expiracao automatica de 48 horas para manter tudo limpo

Busca por Palavras-chave
- Configure grupos de palavras-chave para buscar produtos automaticamente
- A extensao navega no Mercado Livre, encontra produtos e gera links de afiliado em lote
- Ideal para encontrar novos produtos para divulgar

Agendamento Automatico
- Programe buscas automaticas diarias
- Escolha o periodo: manha, tarde, noite ou madrugada
- Horario aleatorio dentro do periodo escolhido para maior naturalidade
- Se o computador estava desligado, executa ao abrir o navegador

Automacao de Coleta
- Colete todos os produtos da pagina atual com um clique
- Gere links de afiliado em lote automaticamente
- Acompanhe o progresso em tempo real com barra de progresso

━━━━━━━━━━━━━━━━━━━━━━━━

COMO FUNCIONA

1. Instale a extensao e faca login com sua conta Achadinho PRO
2. Navegue ate o Mercado Livre — a extensao detecta automaticamente os produtos
3. Use o painel lateral para extrair dados, gerar links e salvar produtos
4. Configure automacoes para buscar produtos regularmente
5. Gerencie suas listas e campanhas pelo web app em achadinhopro.com.br

PERMISSOES E PRIVACIDADE

Esta extensao solicita as seguintes permissoes apenas para funcionar corretamente:

- Acesso a sites do Mercado Livre e Amazon: Para extrair dados publicos de produtos das paginas que voce visita

- Armazenamento: Para salvar suas configuracoes localmente
- Notificacoes: Para alertar sobre tarefas concluidas

NAO coletamos seu historico de navegacao, dados pessoais ou informacoes de outros sites.

DIVULGACAO DE AFILIADOS

O Achadinho PRO e uma ferramenta para afiliados do Mercado Livre. Os links gerados pela extensao contem o identificador de afiliado do usuario. Ao compartilhar esses links, voce pode receber comissoes do Mercado Livre conforme os termos do programa de afiliados. A extensao nao gera receita propria atraves dos links dos usuarios — toda comissao gerada pertence ao usuario afiliado.

## Justificativas de Permissao (para o Privacy tab do dashboard)

### Single Purpose
Ajudar afiliados do Mercado Livre a encontrar produtos, gerar links de afiliado e gerenciar campanhas de divulgacao atraves de extracao de dados de produtos, geracao de links e automacao de buscas.

### Permission: tabs
Necessario para detectar quando o usuario navega em sites de marketplace suportados (Mercado Livre, Amazon) e ler a URL da aba ativa para extrair informacoes do produto para geracao de links de afiliado.

### Permission: activeTab
Permite a extensao interagir com a aba ativa quando o usuario abre o painel lateral, possibilitando a extracao de dados do produto da pagina que o usuario esta visualizando.

### Permission: scripting
Necessario para injetar scripts de extracao (content scripts) nas paginas de produto de marketplaces para coletar dados publicos do produto (titulo, preco, imagem, vendedor).

### Permission: sidePanel
Fornece a interface principal da extensao como painel lateral onde os usuarios navegam pelos produtos, gerenciam listas e configuram automacoes sem sair da pagina do marketplace.

### Permission: storage
Armazena preferencias do usuario, dados em cache e configuracoes da extensao localmente para fornecer uma experiencia continua entre sessoes do navegador.

### Permission: notifications
Notifica o usuario quando tarefas de automacao sao concluidas, quando captchas sao detectados, ou quando acoes requerem atencao do usuario.

### Permission: cookies
Necessario para verificar se o usuario esta logado no programa de afiliados do Mercado Livre, permitindo a geracao de links de afiliado atraves da API do ML.

### Permission: alarms
Agenda verificacoes periodicas para executar buscas automaticas de produtos nos horarios configurados pelo usuario.

### Host: mercadolivre.com.br / mercadolibre.com
Marketplace principal — a extensao extrai dados publicos de produtos (titulo, preco, imagem, vendedor) das paginas do Mercado Livre para gerar links de afiliado e posts de divulgacao.

### Host: amazon.com.br
Marketplace secundario — permite comparacao de produtos e geracao de links de afiliado para produtos da Amazon Brasil.

### Host: achadinhopro.com.br / achadinho.pro
Servidor backend da extensao — necessario para chamadas de API para autenticar usuarios, sincronizar dados de produtos e gerenciar automacoes.
